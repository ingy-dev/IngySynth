# Parameter keys

Generated by `tools/export-params.mjs` from the web app's `js/param-catalog.js` @ `fde5d4c` and from `params-baremetal.json`. Do not edit by hand.

Step keys (`step-slider-N`, `step-fine-N`, `step-accent-N`, `step-slide-N`, `step-toggle-N`, `step-ratch-N`) are never params: they are views of `pattern.slots[slot].steps[N]` (fields `tune`, `fine`, `accent`, `slide`, `on`, `ratch`).

Slot views (`stepCount`, `division`) mirror the selected slot's own `stepCount` / `division`; on load, set them from `pattern.slots[pattern.slot]`.
